# Aula 1.3 — Papéis e Responsabilidades

**Nível:** Iniciante  
**Duração estimada:** 15 minutos  
**Pré-requisito:** Aula 1.2 (As 4 fases)  
**Status:** Em produção

**Resumo:** Aprenda os 5 papéis principais num 45D Sprint e como eles trabalham em paralelo para acelerar execução.

---

## 🎯 Por Que Isto Importa

- **Clarity:** Sem papéis definidos, passas 30% do tempo em "quem faz isto?"
- **Parallelization:** IA propõe (minutos) → PM aprova (segundos) → Especialista executa (horas)
- **No rework:** Papéis claros = zero ambiguidade = zero retrabalho
- **Scalability:** Padrão replicável em múltiplos sprints
- **Accountability:** Cada papel tem responsabilidades explícitas

---

## ⚡ Quick Checklist

- [ ] Identificar os 5 papéis principais (PM, SEO, Technical, Content, Cliente)
- [ ] Entender o padrão: IA propõe → PM aprova → Especialista executa
- [ ] Reconhecer os 3 cenários (Agência, Consultoria, Híbrido)
- [ ] Dominar a cadência de comunicação (4-5 touchpoints/semana)

---

## 📖 Conteúdo Principal

### Os 5 Papéis Principais

#### 1. **Project Manager (PM)**
**Quem:** RankPanda PM ou cliente com papel de PM  
**Responsabilidades:**
- Coordenar entre equipa e cliente
- Approve/reject propostas da IA
- Gatekeep aprovações do cliente
- Resolver blockers imediatamente
- Comunicar status

#### 2. **SEO Specialist**
**Quem:** RankPanda SEO ou cliente SEO-savvy  
**Responsabilidades:**
- Analisar keywords, posições, competição
- Criar briefings para redator
- Validar otimizações técnicas
- Propor estratégia de coleções

#### 3. **Technical**
**Quem:** Dev Shopify ou dev cliente  
**Responsabilidades:**
- Implementar mudanças em Shopify
- Cuidar de redirects, meta tags
- Setup tracking (GA4, GTM)
- Fazer deploy (QA, produção)

#### 4. **Content**
**Quem:** Redator, copywriter, ou cliente com escrita forte  
**Responsabilidades:**
- Escrever descrições, títulos otimizados
- Criar SEO copy para coleções
- Revisar e aprovar antes de deploy
- Manter brand voice

#### 5. **Cliente**
**Quem:** Proprietário loja ou gerente  
**Responsabilidades:**
- Aprovar estratégia (keywords, coleções)
- Feedback em pontos críticos (3 vezes/semana)
- Providenciar acesso e dados
- Validar antes de launch

### Padrão de Execução: IA → PM → Especialista

```
SEGUNDA MANHÃ:
IA (Claude): "Analisei GSC. Top 20 keywords por oportunidade:
  1. 'vibrador silencioso' — 800/mês, 15% CTR, 5ª posição
  2. 'brinquedo discreto' — 600/mês, 12% CTR, 12ª posição
  Proposta: Começar por top 5 + criar conteúdo para top 10"

PM (Rui): "Isto faz sentido. Concordo. Vou apresentar ao cliente."

PM → CLIENTE (Discord): "Aprovam estes keywords? Resposta esperada: 24h"

TERÇA MANHÃ:
CLIENTE: "Aprovado ✅"

SEO: "Criei briefing para redator:
  - KW1: Meta description < 160 chars
  - KW2: Title com long-tail variant
  - KW3: Headers otimizados"

REDATOR: "Briefing recebido. Entrego 3 peças quarta."

QUINTA:
CLIENTE: "Aprovo peças ✅"
TECHNICAL: "Upload feito. GSC submitted."
```

**Pepita #5:** "IA propõe (minutos) → PM aprova (segundos) → Especialista executa (horas). Isto é parallelização real."

### 3 Cenários

#### Cenário A: RankPanda Executa Tudo (Agência)
- PM: Rui (RankPanda)
- SEO: João (RankPanda)
- Technical: Pedro (RankPanda)
- Content: Sara (RankPanda)
- Cliente: Aprova, feedback

✅ Vantagem: Velocidade, consistência, expertise centralizada  
⚠️ Risco: Cliente menos envolvido

#### Cenário B: Cliente Faz Execução (Consultoria)
- PM: Rui (RankPanda)
- SEO: Rui + Cliente consultant
- Technical: Dev cliente
- Content: Redator cliente
- Cliente: Coordena internamente

✅ Vantagem: Cliente aprende, ownership forte  
⚠️ Risco: Mais lento (outras prioridades)

#### Cenário C: Híbrido (Mais Comum)
- PM: Rui (RankPanda)
- SEO: João + Cliente consultant
- Technical: Pedro (RankPanda)
- Content: Sara + redator cliente
- Cliente: Aprova, feedback

✅ Vantagem: Velocidade + aprendizagem + scalability  
⚠️ Risco: Coordenação entre partes

**"Na RankPanda, fazemos Cenário A por default. Clientes que querem Cenário B pagam menos. Cenário C é o mais comum."**

### Cadência de Comunicação

| Dia | Hora | O Quê | Quem | Duração |
|-----|------|-------|------|---------|
| **Segunda** | 10:00 | Kickoff ou Status check | PM + Equipa + Cliente | 1h |
| **Terça** | 14:00 | Mid-week diagnostics | PM + Specialists | 30min |
| **Quarta** | 16:00 | Approval gate (keywords, descriptions) | PM + Cliente | 15-30min |
| **Sexta** | 10:00 | Weekly status + metrics | PM + Equipa | 30min |
| **Sexta** | 16:00 | Cliente update (Discord) | PM | 5min (async) |

**Extra:** Escalação imediata se algo fica bloqueado (e-mail, Discord mention)

### Resumo

- **5 Papéis:** PM, SEO Specialist, Technical, Content, Cliente
- **1 Padrão:** IA propõe → PM aprova → Especialista executa
- **3 Cenários:** Agência, Consultoria, Híbrido
- **1 Cadência:** 4-5 touchpoints/semana, aprovações on-demand

**Pepita #6:** "Papéis claros = zero retrabalho. Papéis confusos = 30% do tempo em reuniões."
