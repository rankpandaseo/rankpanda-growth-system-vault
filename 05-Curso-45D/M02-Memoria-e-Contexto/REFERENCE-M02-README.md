# M02 — Memória e Contexto: Como Claude Code Sempre Sabe

**Resumo:** Sistema de memória persistente que permite ao assistente IA ser operacional real, não apenas um chatbot. Cada sessão começa WHERE A ANTERIOR PAROU — contexto, decisões, lições, estado de projetos, tudo sincronizado.

---

## 🎯 Por Que Isto Importa

- **Session continuity:** Sem memória, cada sessão = reset completo. Com memória, Rui começa a sessão nova e Claude já sabe que ontem terminámos ETAPA 2, temos ETAPA 3-5 pendentes, decisão X foi tomada.
- **Scaling operational AI:** IA que esquece tudo é um chatbot. IA que lembra contexto, decisões, lições é um parceiro operacional que fica mais inteligente a cada sprint.
- **Disaster prevention:** Memória de lições (o que falhou, o que funcionou) evita repetir erros. Memória de decisões evita contradições. Memória de estado evita perder progresso.
