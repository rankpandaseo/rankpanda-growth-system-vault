# SOP FASE 0 — Kickoff (3-5 dias)

**Resumo:** Alinhar negócio com cliente, recolher acessos técnicos, desenhar baseline de métricas, preparar organização (Obsidian, Discord, ClickUp) para sprint.

---

## 🎯 Por Que Isto Importa

- **Clareza de expectativas:** Kickoff não é "vamos fazer SEO". É "implementaremos SOP 1-5 nesta ordem, com aprovações aqui, e esperamos X resultados". Sem isto, cliente tem expectativas irrealistas.
- **Validação técnica:** Todos os acessos API testados ANTES de iniciar. Não descobrimos GSC broken na FASE 1.
- **Baseline para análise:** Capturamos snapshot (dia 0) de indexed, impressions, clicks, position. Qualquer análise futura compara contra este baseline.

---

## ⚡ Quick Checklist

**Kickoff Call (1 dia):**
- [ ] Kickoff call agendada e concluída (1h)
- [ ] Briefing form (negócio + técnico) preenchido
- [ ] Modelo de negócio compreendido (dropshipping, estoque próprio, marketplace, etc)
- [ ] AOV (Average Order Value) e volume mensal conhecidos

**Validação Técnica (1-2 dias):**
- [ ] Acesso Shopify admin confirmado (OAuth integrado)
- [ ] Google Search Console vinculado
- [ ] Google Analytics 4 ativo e com eventos configurados
- [ ] SE Ranking API key validada
- [ ] Robots.txt existente e analisado
- [ ] Sitemap.xml existente

**Setup Operacional (1 dia):**
- [ ] Discord channel criado + cliente convidado
- [ ] ClickUp space criado com templates
- [ ] Obsidian vault `/memory/projects/[loja]/` inicializado

**Validação & Baseline (1 dia):**
- [ ] Baseline metrics capturados (indexed, impressions, clicks, avg position)
- [ ] Roadmap visual de 45 dias aprovado com cliente
- [ ] Go/No-go decision tomada → Pronto para [[FASE-1-DIAGNOSTIC]]

---

## 📖 Conteúdo Principal

### 🔑 Key Principles

1. **Clarity First:** Kickoff não é "vamos fazer SEO". É "implementaremos SOP 1-5 nesta ordem, com aprovações aqui, e esperamos X resultados".
2. **Technical Validation:** Todos os acessos API testados ANTES de iniciar. Não descobrimos GSC broken na FASE 1.
3. **Baseline is Truth:** Capturamos snapshot (dia 0) de indexed, impressions, clicks, position. Qualquer análise futura compara contra este baseline.
4. **Shared Ownership:** Cliente sabe que vai receber relatórios semanais, vai ser consultado em decisões estratégicas, tem propriedade do resultado.
5. **Operational Excellence:** Obsidian + Discord + ClickUp integrados desde dia 1. Zero fricção para comunicação e documentação.

### 📋 Fluxo de Kickoff Call (60 min)

1. **Contexto (10 min)** — Explicar o que é 45D, 4 fases, entregáveis
2. **Negócio (15 min)** — Entender loja, AOV, target, concorrência
3. **Expectativas (10 min)** — O que é realista esperar, desmistificar SEO
4. **Processo (15 min)** — Explicar aprovações, timeline, comunicação
5. **Acessos (10 min)** — Listar o que precisamos, confirmar prazos
