Como Fazer GSC Analysis 1. **Abrir GSC** → "Coverage" report
2. **Ler gráfico de cobertura:** - Linhas vermelhas (erros) → normalmente 404s
ou bloqueadas - Linhas laranja (aviso) → descobertas mas não indexadas - Linhas
azuis (sucesso) → indexadas
3. **Identificar padrões:** - Todas as products têm erro? → Canonical issue,
robots.txt bloqueando, etc - Coleções indexadas mas não products? → Estrutura
problema - Tudo OK mas poucas impressões? → Problema de visibilidade (content,
links) 4. **Documentar findings:** - Quantas páginas indexadas? - Quantas
descobertas mas não indexadas? - Qual é o gap? ### Como Fazer GA4 Analysis 1.
**Ir a Acquisition → Organic Search**
2. **Analisar trending:** - Sessions growing, flat, or declining? - From which
pages is traffic coming? - What's the conversion rate? 3. **Analisar landing
pages:** - Top 10 pages by sessions - Compare bounce rate (high bounce =
problema) - Compare conversion rate 4. **Documentar:** - Organic sessions/month
(trend) - Top 3 landing pages - Average conversion rate - Where is the traffic
going? (categories, products, blog?) ### Como Mapear Competitive Landscape 1.
**Identificar top 5 competitors** (SEO, não só brand)
2. **Para cada competitor, analisar:** - Usando SE Ranking ou similar: top 20
keywords ranked - Collection structure (quantas coleções, nomes, keywords) -
Content strategy (têm blog? Quanto conteúdo?) - Backlink profile (rough) 3.
**Documentar gaps vs competitors:** - Keywords eles rankeiam que nós não -
